# homebrew tap

personal homebrew tap - installs my macos apps from source (no code signing or
notarization, so nothing is flagged by gatekeeper).

## install

    brew tap hesennivas/tap
    brew install <formula>

## formulae

| formula     | description                                              |
| ----------- | -------------------------------------------------------- |
| `webbridge` | native macos cockpit for android & ios webview debugging |
